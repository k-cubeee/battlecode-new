# Cambridge Battlecode 2026 bots

A [cambc](https://2026a.battlecode.co.uk/game/download) workspace for Python bots.

- **New here? Start with [docs/GUIDE.md](docs/GUIDE.md)**: how the game and your program work, the API
  you'll use, and a step-by-step roadmap for building your own bot.
- Your bot lives in `bots/my-bot/`. `starter-python` and `v19` are opponents to test against.
- Setup: `python3 -m pip install --upgrade cambc`
- Play a match: `cambc run my-bot starter-python --view`
- Benchmark: `python3 scripts/bench.py my-bot starter-python --sample 10`
